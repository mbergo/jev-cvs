Setup

  1. Add the new group to GROUP_CATEGORY in src/data/controlPlaneRules.ts (first lines of the snippet).
  2. Append the rule({...}) entries to INITIAL_CONTROL_PLANE_RULES.
  3. Add each "benign near-miss" from the tables above to NEGATIVE_PRESET_PROMPTS so false positives are tested.
  4. "Healthcare Conduct" is mapped to the existing prompt_injection category, as "Harmful Content" already is. A dedicated category would need a change to the policy schema.
